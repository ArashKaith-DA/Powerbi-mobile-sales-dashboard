# Mobile Sales Analysis Dashboard | Power BI

## Project Overview

This project analyzes mobile sales data using Microsoft Power BI. The dataset includes transaction details, mobile brands and models, units sold, prices, customer ratings, cities, and payment methods.

The objective is to explore sales performance and customer purchasing patterns through interactive visualizations.

## Tools Used

- Microsoft Power BI
- Microsoft Excel
- Data visualization and analysis

## Dataset Overview

The supplied dataset contains 3,835 transaction records and 14 columns, covering:

- Mobile brands and models
- Units sold and price per unit
- Transaction date components
- Customer age and ratings
- City and payment method

The dataset includes five brands, 15 mobile models, and 19 cities.

## Analysis Areas

- Sales performance by mobile brand
- Sales trends over time
- City-wise sales distribution
- Mobile model performance
- Customer ratings
- Payment method preferences
- Units sold and sales value

## Key Findings

- The dataset contains 3,835 transaction records and 19,150 units sold.
- Apple has the highest recorded transaction count among the five brands, with 783 transactions.
- Delhi has the highest transaction count among the cities, with 1,008 transactions.
- UPI is the most frequently recorded payment method, with 1,011 transactions.
- The average customer rating is approximately 3.69 out of 5.

## How to Use

1. Download the Power BI dashboard file.
2. Open it using Microsoft Power BI Desktop.
3. If prompted, update the data source path to the location of the Excel dataset.
4. Refresh the data if required.
5. Explore the report pages, filters, and visualizations.
